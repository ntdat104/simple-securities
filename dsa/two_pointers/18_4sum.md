# 18. 4Sum

## Problem Description

Given an array `nums` of `n` integers, return an array of all the **unique** quadruplets `[nums[a], nums[b], nums[c], nums[d]]` such that:

- `0 <= a, b, c, d < n`
- `a`, `b`, `c`, and `d` are **distinct**.
- `nums[a] + nums[b] + nums[c] + nums[d] == target`

You may return the answer in **any order**.

### Example 1:

**Input:** `nums = [1,0,-1,0,-2,2], target = 0`  
**Output:** `[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]`

### Example 2:

**Input:** `nums = [2,2,2,2,2], target = 8`  
**Output:** `[[2,2,2,2]]`

### Constraints:

- `1 <= nums.length <= 200`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`

## Solution (Golang)

### Approach: Sorting + Nested Loops + Two Pointers

Similar to 3Sum, we sort the array and use nested loops to fix the first two numbers, then use two pointers to find the remaining two.

```go
import "sort"

func fourSum(nums []int, target int) [][]int {
    sort.Ints(nums)
    n := len(nums)
    res := [][]int{}

    for i := 0; i < n-3; i++ {
        // Skip duplicate for i
        if i > 0 && nums[i] == nums[i-1] {
            continue
        }
        for j := i + 1; j < n-2; j++ {
            // Skip duplicate for j
            if j > i+1 && nums[j] == nums[j-1] {
                continue
            }

            left, right := j+1, n-1
            for left < right {
                sum := nums[i] + nums[j] + nums[left] + nums[right]
                if sum == target {
                    res = append(res, []int{nums[i], nums[j], nums[left], nums[right]})
                    left++
                    right--
                    // Skip duplicates for left and right
                    for left < right && nums[left] == nums[left-1] {
                        left++
                    }
                    for left < right && nums[right] == nums[right+1] {
                        right--
                    }
                } else if sum < target {
                    left++
                } else {
                    right--
                }
            }
        }
    }
    return res
}
```

## Explanation

1.  **Sorting**: We sort the array first to make it easier to avoid duplicates and use the two-pointer technique.
2.  **Nested Loops**: We use two nested loops (with pointers `i` and `j`) to lock in the first two elements of the potential quadruplet.
3.  **Two Pointers**: After fixing `i` and `j`, we use the two-pointer approach (`left` and `right`) to find the other two numbers that complete the `target` sum.
4.  **Avoiding Duplicates**: 
    -   Inside each loop, we check if the current number is the same as the previous one. If so, we skip it.
    -   When we find a valid sum, we also skip all identical numbers for `left` and `right` to ensure the quadruplets in the result are unique.

## Complexity

-   **Time Complexity**: $O(n^3)$. We have two nested loops, and the third dimension is handled by the two-pointer traversal which is $O(n)$.
-   **Space Complexity**: $O(1)$ or $O(n)$ depending on the implementation of the sorting algorithm, as we don't use any significant extra storage beyond the result.

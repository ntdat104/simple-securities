# 15. 3Sum

## Problem Description

Given an integer array `nums`, return all the triplets `[nums[i], nums[j], nums[k]]` such that `i != j`, `i != k`, and `j != k`, and `nums[i] + nums[k] + nums[k] == 0`.

Notice that the solution set must not contain duplicate triplets.

### Example 1:

**Input:** `nums = [-1,0,1,2,-1,-4]`  
**Output:** `[[-1,-1,2],[-1,0,1]]`  
**Explanation:** 
`nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0`.
`nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0`.
`nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0`.
The distinct triplets are `[-1,0,1]` and `[-1,-1,2]`.
Notice that the order of the output and the order of the triplets does not matter.

### Example 2:

**Input:** `nums = [0,1,1]`  
**Output:** `[]`  
**Explanation:** The only possible triplet does not sum up to 0.

### Example 3:

**Input:** `nums = [0,0,0]`  
**Output:** `[[0,0,0]]`  
**Explanation:** The only possible triplet sums up to 0.

### Constraints:

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## Solution (Golang)

### Approach: Sorting and Two Pointers

To avoid duplicates and efficiently find triplets, we first sort the array. Then, for each element `nums[i]`, we treat it as a fixed element and use two pointers (`left` and `right`) to find the other two elements that sum to `-nums[i]`.

```go
import "sort"

func threeSum(nums []int) [][]int {
	sort.Ints(nums)
	var result [][]int
	n := len(nums)

	for i := 0; i < n-2; i++ {
		// Skip duplicate fixed elements
		if i > 0 && nums[i] == nums[i-1] {
			continue
		}

		target := -nums[i]
		left, right := i+1, n-1

		for left < right {
			sum := nums[left] + nums[right]
			if sum == target {
				result = append(result, []int{nums[i], nums[left], nums[right]})
				left++
				right--
				// Skip duplicates for the second element
				for left < right && nums[left] == nums[left-1] {
					left++
				}
				// Skip duplicates for the third element
				for left < right && nums[right] == nums[right+1] {
					right--
				}
			} else if sum < target {
				left++
			} else {
				right--
			}
		}
	}

	return result
}
```

## Explanation

1.  **Sorting**: Sorting the array allows us to use the two-pointer approach efficiently.
2.  **Fixed Element**: We iterate through the array with pointer `i`. If `nums[i]` is positive, we can stop early because any two following numbers will also be positive (since the array is sorted), making the sum strictly greater than 0.
3.  **Handling Duplicates**: 
    -   For the fixed element: `if i > 0 && nums[i] == nums[i-1]`, we `continue` to avoid repeating the same search.
    -   After finding a triplet, we use `while` loops to skip duplicate values for the `left` and `right` pointers.
4.  **Two Pointers**: We shrink the window from `[i+1, n-1]` based on whether the `sum` is too small or too large compared to the `target` (`-nums[i]`).

## Complexity

-   **Time Complexity**: $O(n^2)$, where $n$ is the length of the array. The sorting takes $O(n \log n)$, and the nested loop with two pointers takes $O(n^2)$.
-   **Space Complexity**: $O(n)$ or $O(1)$ depending on the sorting implementation's auxiliary space. We do not use any additional data structures proportional to the input size other than the output array.
